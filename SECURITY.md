# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Cakwe seriously. If you believe you have discovered a security vulnerability or vulnerability in the ingestion / parsing pipelines:

1. **Do not create a public issue** on GitHub.
2. Please privately report it to the maintainer or send details via GitHub Security Advisories.
3. Include detailed steps to reproduce the issue along with a proof of concept if applicable.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to resolve the issue promptly before public disclosure.
